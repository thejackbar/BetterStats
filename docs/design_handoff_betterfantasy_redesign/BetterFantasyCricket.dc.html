System
Tokens drive light/dark — wire data-theme on the root. Accent is one var (--pb-accent #8C82F0) so it stays white-labelled per club. Player avatars = photo, club crest fallback. Fonts: Saira Condensed (display) + Hanken Grotesk (UI). Maps straight onto the existing BetterFantasyCricket API (fanMe / fanPool / fanLadder / fanLeagues / fanRound / fanDraft…).
